


## Guia de iniciación





### Nos posicionamos en la carpeta ´admin´ y ejecutamos para instalar las dependencias:

```sh
    poetry install 
```

> [!NOTE]
> Notamos que si usamos el entorno activo, no es necesario ejecutar poetry run cada vez qu ejecutemos nuestro código

<details>

<summary>Detalles sobre poetry </summary>

### Luego de ejecutar poetry install

Se genera un archivo poetry.lock el cuál contiene las dependencias que instala en el proyecto

### Luego, podemos utilizar poetry directamente activando el entorno.
```sh
   poetry shell
```

> [!TIP]
> Notamos que si usamos el entorno activo, no es necesario ejecutar poetry run cada vez qu ejecutemos nuestro código
